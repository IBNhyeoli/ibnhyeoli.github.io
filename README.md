# 계원 길잡이

명일방주 통합전략 「쉐이의 기이한 계원」 엔딩 가이드.

사이트: https://ibnhyeoli.github.io/

엔딩 5개, 사전 해금 조건, 필수 소장품, 진행 체크리스트를 제공합니다. 체크 기록은 브라우저에 저장되며 기기 간 동기화되지 않습니다.

HTML/CSS/JavaScript 정적 사이트이며 `data.js`에서 정보를 수정할 수 있습니다. 각 엔딩 화면에 참고 출처가 표시됩니다.

한국어 공략과 커뮤니티 위키를 참고한 초안입니다. 게임 내 검증 및 한국 서버 최신 패치 대조는 미완료이며, 강화 단계별 상세 경로는 포함하지 않았습니다.
